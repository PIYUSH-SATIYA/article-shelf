# Frontend Spec

## Stack

- React
- Vite
- TypeScript
- Tailwind

## UX Goals

- Fast capture
- Calm browsing
- Low friction
- Mobile-friendly

## Main Views

### Home

Sections:

- Currently Reading
- Inbox
- High Priority
- Archive Preview

### Archive Page

Full archived article listing.

### Article Detail

View:

- title
- url
- reason
- notes
- tags
- metadata

### Add Article Modal

Fields:

- URL
- Title
- Reason
- Tags
- Priority

## Features

- Search
- Filtering
- CSV import/export
- Responsive layout

## Constraints

- No auth
- No notifications
- No AI
- No infinite configuration
